📝 How the Proxy Works

Browser request: http://localhost:3002/api/auth/auth/login ↓ (Vite proxy) Actual request to: http://localhost:8080/api/auth/auth/login ↓ (backend processing) Returned to browser: response data This way the browser thinks the request is same-origin (both are localhost:3002), but the backend is actually being handled at localhost:8080.
