📋 Common Causes of 403 Errors and Solutions

Cause Symptom Solution
Missing CSRF Token Postman works, browser gets 403 Disable CSRF on the backend or add a CSRF Token on the frontend
Referer check Specific requests get 403 Backend should allow the localhost:3002 Referer
Authorization Header 403 on endpoints requiring authentication Ensure the Token is passed correctly
Request method restriction POST gets 403, GET works fine Backend should allow that HTTP method
